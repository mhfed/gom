# Tin Nhan 0.3 Implementation Plan

> Execution: primary implements inline with superpowers:executing-plans; one bounded read-only integration reviewer before delivery. User approved the roadmap and requested execution; no additional approval gate for routine implementation decisions.

Goal: reliable recovery, native macOS controls and native platform notifications, retaining independent sessions and existing shell.
Architecture: add small pure recovery, preference/bounds and notification-policy modules. Main owns OS integration. A sandboxed notification-only remote preload adds a click listener to page-created native Notification objects; sends no content and can only focus its own existing provider view through validated sender/main-frame IPC. Keep provider-origin sandbox and navigation allowlist. No synthetic alerts based on unread, no message index/backend, no automatic release publication.

Contract: native platform notifications have ask/allow/mute per provider, global pause, remembered choice; test button and OS settings link. Respect mute at permission check/request. Constructor click bridge covers document-created notifications; service-worker notifications retain platform handling and require live verification. No claims that all platforms emit notifications. Dock badge is a bullet if any supported positive count, never a sum of mixed units. Startup default off; fixed global show/hide shortcut optional and failure reported. Menu-bar menu offers open/providers/pause/quit. Back/home act on selected provider only. Restore valid visible window bounds. Retry only failed pages, bounded backoff; no healthy-page reload on wake/network recovery. Distinguish offline/load/crash/blocked/login states. Preserve sessions and Cmd+W/Cmd+Q contract.

Files: src/main/{recovery,preferences,notification-policy,platform-preload}.ts; integrate src/main/main.ts, preload.ts, shared.ts, renderer files, scripts/build.mjs. Tests in tests/desktop.test.ts and isolated Electron scripts/desktop-check.mjs; reuse persistence/window/theme harnesses.

Review focus: stale async results after navigation; malformed saved preferences/bounds; offsite subframe notification permissions/IPC; notification click while hidden/after restart and mute; retry loops or draft-destructive wake handling.
