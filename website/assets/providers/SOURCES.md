# Brand assets

- Zalo: https://stc-zlogin.zdn.vn/images/favicon.png, linked by the official https://id.zalo.me/ sign-in page.
- Telegram: https://telegram.org/img/t_logo.svg, official site asset. Brand resources: https://telegram.org/tour/screenshots.
- Messenger: https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/messenger.svg; vector shape from Simple Icons, primary #0866FF per Meta's February 2025 brand guidance: https://www.meta.com/brand/resources/facebook/messenger-icon/.
- Tinder: flame path from https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/tinder.svg, presented on a local rounded tile in Simple Icons' #FF6B6B brand color. Simple Icons is CC0: https://simpleicons.org/.
- Gmail, Instagram, Discord and Slack: locally authored compact SVG marks using each service's recognizable symbol and brand colors; no runtime logo requests.

Bundled locally; the app makes no runtime logo requests.
